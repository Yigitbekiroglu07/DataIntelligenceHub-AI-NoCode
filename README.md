## 📊 1. Data Science & Data Visualization

📁 [`DataScience/`](./DataScience)

An end-to-end data cleaning and exploratory data analysis (EDA) workflow applied to an e-commerce dataset.

**Topics covered:**
- Detecting and handling missing values (dropping / imputing)
- Removing duplicate records
- Fixing and standardizing data types
- Outlier detection and analysis
- Data visualization with `matplotlib`, `seaborn`, and `plotly`

**Tools used:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `plotly`

---

## 🧠 2. Machine Learning

📁 [`MachineLearning/`](./MachineLearning)

A hands-on collection of supervised and unsupervised learning algorithms.

**Topics covered:**
- Data preprocessing (Label Encoding, One-Hot Encoding, Standardization/Normalization)
- Classification: `Logistic Regression`, `Decision Tree`, `K-Nearest Neighbors`
- Clustering: `K-Means`, hierarchical clustering
- Dimensionality reduction: `PCA`
- Model selection & hyperparameter tuning: `GridSearchCV`, `Pipeline`

**Tools used:** `scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`

---

## 🔬 3. Deep Learning

📁 [`DeepLearning/`](./DeepLearning)

Neural network and convolutional neural network applications on image and sequence data.

**Topics covered:**
- Artificial Neural Networks (ANN) for MNIST handwritten digit classification
- Convolutional Neural Networks (CNN) for CIFAR-10 image classification
- NLP fundamentals (tokenization, embedding layers)
- Overfitting/underfitting analysis (accuracy vs val_accuracy)

**Tools used:** `TensorFlow`, `Keras`, `gensim`, `scikit-learn`, `numpy`, `pandas`, `matplotlib`
